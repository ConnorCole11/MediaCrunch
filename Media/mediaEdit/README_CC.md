# Purpose
To easily edit media types that **FOR SOME REASON** are not editable by iphone and stuff. Example: cropping a gif (why not???), cutting gifs (why not???), image/video/gif resolution (wy not???), video speed (WHY NOT???), bitrate (fair enough) etc. 

# Parts
## Main
The main, overall editor. Runs the editor selected: video, gif, image, etc. (Not yet implemented)

## videoEdit
Edits videos. 

## gifEdit
Edits gifs.

## imageEdit
Edits images.

## convertFormat
Can change the following formats (input -> outputs):
video -> gif
gif -> video
image -> video, gif

## audioEdit
An audio editor. Changes volume, crops, snips, etc. Not sure how fancy I'll get, but it will mostly exist for volume and audio quality, because sometimes worse quality is funnier.

## hybridEdit
For combining different formats, mostly video and audio.

## memeTemplates (not made yet)
Will probably add some templates, like adding certain songs or doing that flashing white -> repeated video template for dumb dramatic stuff.
